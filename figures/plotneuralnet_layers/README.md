# PlotNeuralNet layer styles

These LaTeX layer styles are vendored from [HarisIqbal88/PlotNeuralNet](https://github.com/HarisIqbal88/PlotNeuralNet), used under its MIT license. They are used by `walkernet_plotneuralnet.tex` to render the alternative 3-D architecture figure.

The generator also vendors the small Python `pycore.tikzeng` module under `scripts/plotting/pycore/` so the figure can be regenerated without a user-specific checkout path.
