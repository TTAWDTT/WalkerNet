# CNOP paper-ready figure bundle v2

The common_scale_tos08_zos003 directory contains the cross-basin comparison set rendered from the existing Pacific normal/delayed and Global delayed CNOP artifacts. No CNOP optimization or model training was rerun.

Display convention for every response-evolution figure:

- TOS: ±0.8 °C
- ZOS: ±0.03

The bundle contains 80 PNG files:

- Pacific normal: 30 response-evolution figures (ranks 1–3).
- Pacific delayed: 30 response-evolution figures (ranks 1–3) plus 10 candidate panels.
- Global delayed: 10 rank-1 response-evolution figures.

The earlier paper_ready_v1 bundle and the original auto-scaled Pacific figures remain unchanged for provenance.
