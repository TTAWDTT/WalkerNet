# CNOP response-evolution figure organization

The direct children are the clean delivery set requested for visual review:

- `overview/`: exactly three overview figures — Pacific delayed, Global delayed, and Indian.
- `Pacific/`: Pacific normal response-evolution figures (30 PNGs; ranks 1–3).
- `pacific delay/`: Pacific delayed response-evolution figures (30 PNGs; ranks 1–3).
- `indian/`: Indian response-evolution montage.
- `global/`: Global normal response-evolution montage.
- `global delay/`: Global delayed rank-1 response-evolution figures (10 PNGs).

The response-evolution figures in `Pacific/`, `pacific delay/`, and `global delay/` use the common display convention `TOS ±0.8 °C` and `ZOS ±0.03`. No CNOP optimization or model training was rerun for this reorganization.

All previous layouts, intermediate products, and source figure bundles were preserved under `_archive_before_final_organized/` and are not part of the clean delivery set.
