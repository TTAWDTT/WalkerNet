# Pacific delayed overview: smoothed raster variant

`pacific_delay_overview_smoothed.png` is a display-only raster refinement of the existing `pacific_delay_overview.png`.

- Only the ten left-column initial-delta-TOS map interiors were processed.
- The ocean raster was cubically upsampled and masked-Gaussian smoothed.
- White land/invalid pixels, panel borders, labels, colorbars, and the three response columns were preserved.
- No CNOP, response, truth, baseline, or perturbed values were recomputed or changed.
