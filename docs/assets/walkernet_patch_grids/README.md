# Pure rectangular WalkerNet patch grids

These are geometry-only 2:1 rectangular diagrams with no sample field, map projection, land mask, or TOS values.

- `walker_net_pure_grid_45x90`: dense `45×90=4050` grid, corresponding to exact `4°×4°` WalkerNet patches.
- `walker_net_pure_grid_23x44`: coarse `23×44=1012` grid, approximately one quarter of the dense cell count.

Blue lines and pale-yellow alternating cells are purely visual aids.
